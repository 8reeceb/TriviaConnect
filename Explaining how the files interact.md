Explaining the file situation

app.py is what uses the flask framework. it uses index.html as the app template and TriviaDatabases.py to generate the tables from all the .txt files
populatingdatabase.py populates the trivia database using the TriviaDatabases.py file. The generated databases are then stored in TriviaApp.db.
index.html is the file that makes the app appear on the screen.
style.css is the file that styles the app with color and proper spacing.
